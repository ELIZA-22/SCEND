# SCEND - Executive Protection Platform

Nigeria's first technology-enabled platform for professional executive protection services.

## 🎯 About

SCEND connects high-net-worth individuals, corporations, and executives with verified security professionals across Nigeria. Our platform provides on-demand, professional executive protection services with full transparency and accountability.

## ✨ Features

- **Professional Landing Page** with hero section and service offerings
- **4-Step Security Request Form** for easy booking
- **Coverage in 6 Major Cities**: Lagos, Abuja, Port Harcourt, Ibadan, Kano, Enugu
- **Responsive Design** - works on all devices
- **Modern UI/UX** with Tailwind CSS and glassmorphism effects
- **Parallax Scrolling** for engaging user experience

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (React 19)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v3.4.1
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/scend.git
cd scend
```

2. Install dependencies:
```bash
cd client
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🚢 Deployment

### Deploy to Vercel (Recommended)

1. Push your code to GitHub
2. Visit [vercel.com](https://vercel.com)
3. Import your repository
4. Vercel will auto-detect Next.js and deploy

### Build for Production

```bash
cd client
npm run build
npm start
```
