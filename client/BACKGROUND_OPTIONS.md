## 🎨 Alternative Options (If You Want Different Style)

### Option 2: Teal Accent Gradient
More colorful with teal focus:

```tsx
className="bg-gradient-to-br from-teal-900 via-slate-900 to-slate-900"
```

### Option 3: Subtle Pattern Background
Dark with geometric pattern:

```tsx
className="bg-slate-900"
style={{ backgroundImage: 'url("data:image/svg+xml,...pattern...")' }}
```

### Option 4: Use the Other Image
Try the other security image you uploaded:

```tsx
backgroundImage: "url('/images/hero-bodyguard.jpg')"
```

### Option 5: Animated Gradient
Modern moving gradient effect:

```tsx
className="bg-gradient-to-br from-slate-900 via-teal-900 to-slate-900 animate-gradient"
```
