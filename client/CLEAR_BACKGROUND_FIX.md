## 🎨 Fine-Tuning Options

### Make Image Even MORE Visible
```tsx
// Increase opacity to 80%
<div className="... opacity-80" />

// Remove left gradient completely
<div className="... from-transparent via-transparent to-transparent" />
```

### Keep Image Visibility but Darken Text Area
```tsx
// Increase left gradient only
<div className="... from-slate-900/70 via-transparent to-slate-900/40" />
```
